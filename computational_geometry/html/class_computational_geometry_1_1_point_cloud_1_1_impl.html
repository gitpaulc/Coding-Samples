void ComputationalGeometry::PointCloud::Impl::naiveTriangulate ( std::vector< Triangle2d > & ioTriangulation,
std::vector< point2d > & ioPointArray,
std::vector< point2d > & ioHull )

This is O(n^2 log(n)) where n is the number of vertices. For every vertex, iterate over the number of faces a constant number of times. The number of faces in any triangulation is 2n - size(hull) - 2 which is O(n). So iterating over the faces is O(n log(n)) This gives a total of O(n^2 log(n)).
